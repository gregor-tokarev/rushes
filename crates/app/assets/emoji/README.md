# Page icon images

Colour emoji images for the page icons Rushes offers (the icon picker, the
script templates and the sample videos), so they render the same in every
place and on every platform.

Source: [Noto Emoji](https://github.com/googlefonts/noto-emoji) by Google,
`2D/png/128/emoji_u<codepoints>.png` at commit `e20cbc2b`, saved as
`<codepoints>.png` (lower-case hex code points joined by `_`, without the
variation selector U+FE0F).
